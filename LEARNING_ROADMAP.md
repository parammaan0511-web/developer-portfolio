- **College Subjects:** Programming for Problem Solving (Python/C++), Engineering Mathematics, Computer Fundamentals & Linux Lab (CSE103), Basic Electronics
- **Skills to Focus On:** Writing clean Python code, using Linux terminal without relying on GUI, Git commits/branches, basic REST API calls with curl

### Semester 2 — Core Programming & Data Structures
- **College Subjects:** Data Structures & Algorithms, Object-Oriented Programming (C++/Python), Discrete Mathematics, Digital Logic
- **Skills to Focus On:** Arrays, linked lists, stacks, queues, trees, recursion, and Python classes/objects

### Semester 3 — Databases & Web Fundamentals
- **College Subjects:** Database Management Systems (DBMS), Operating Systems, Computer Networks, Design & Analysis of Algorithms
- **Skills to Focus On:** MySQL queries, joins, keys, normalization, plus HTML, CSS, and basic JavaScript
- **Project:** **Student Attendance & Marks Tracker** (Python + MySQL) and a clean frontend web app (**Qartix**)
- **Certification Goal:** Google IT Support Certificate (Coursera audit)

### Semester 4 — Backend & Building Full Apps
- **College Subjects:** Artificial Intelligence Basics, Software Engineering, Probability & Statistics, Web Technologies
- **Skills to Focus On:** Building simple backend APIs using Flask or FastAPI, connecting frontend with SQLite/MySQL
- **Project:** **Study & Assignment Reminder Web App** (Flask + SQLite + HTML/CSS) where students can track lab deadlines
- **Certification Goal:** AWS Cloud Practitioner Essentials (free course on AWS Skill Builder)
- **Practice:** Start solving LeetCode Medium problems (target 25–30) and revise core OS/DBMS concepts

### Semester 5 — Specialisation (Track B: Data Science & AI / ML)
- **College Subjects:** Machine Learning, Deep Learning, Natural Language Processing, Big Data Analytics

- **Projects:**

  2. **College FAQ / Notes Helper Bot** using basic NLP techniques with a working GitHub repo
- **Internship:** Apply for a 6–8 week summer internship in Python development or Data/ML roles (start applying in Sem 4)
- **Certification Goal:** DeepLearning.AI Machine Learning Specialization or TensorFlow Developer prep
- **Practice:** Explore 2–3 public datasets on Kaggle and upload clean Jupyter notebooks

### Semester 6 — Capstone & Placement Prep

- **Resume & Profiles:** Update resume to include 3 working projects, internship experience, and verified certificates; keep 5+ clean pinned repos on GitHub
- **Placements:** Prepare for campus placement rounds — aptitude, Python/SQL coding rounds, and project discussions
